# BJJ Tracker 🥋

Aplicativo Android para acompanhamento da rotina de treinos de Jiu-Jitsu, registro de consistência e catálogo de técnicas aprendidas.

## Funcionalidades

### 📓 Diário de Treinos
Registro de cada treino com:
- Data
- Duração
- Parceiros de treino
- Foco do dia (guarda, passagem, finalizações, defesas)

### 📚 Biblioteca de Técnicas
Catálogo de técnicas categorizadas por posição.

### 📈 Frequência
Contador visual de presença no tatâme para acompanhamento até a próxima graduação.

## Arquitetura

O projeto segue o padrão **MVVM**, com elementos de **MVI**

## Como executar

1. Clone o repositório
2. Abra o projeto no Android Studio
3. Execute o app em um emulador ou dispositivo
